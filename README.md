# what it is first

AI로 웹사이트를 만들 때, 처음 보는 사람이 각 개념이 **무엇인지**부터 이해하도록 문구를 쓰게 하는 스킬입니다.

AI는 소개 문구에서 가장 인상적인 부분을 앞에 내세우기 쉽습니다. 특이한 성질, 큰 숫자, "~가 아니다" 같은 부정문이 정의보다 먼저 나오면, 처음 보는 사람은 무엇에 대한 이야기인지 모르는 채로 읽게 됩니다.

| 이런 문구 대신 | 이렇게 씁니다 |
| --- | --- |
| **접수원은 판단하지 않는다.** | **접수원은 소명을 받는다.** 소명은 규칙 일부의 예외를 인정받으려는 청구다. |
| 검게 보인다. 끝이 보이지 않는다. 약 40km 위로는 아무것도 오를 수 없다. | 왕이 세운 것으로 알려진, 안쪽 세계와 바깥을 가르는 경계. 바깥의 멸망이 안으로 들어오는 것을 막는다. 검게 보이고… |
| **더 이상 기다리지 않아도 됩니다.** | **자동 결제** — 등록한 카드로 매달 정해진 날에 요금을 결제하는 기능. |

세계관 소개 사이트, 서비스·제품 소개, 단체나 포트폴리오 소개처럼 독자가 모르는 개념을 소개하는 페이지라면 어디에나 쓸 수 있습니다.

## 스킬이 지키게 하는 것

- 개념을 처음 꺼낼 때 첫 문장은 "그게 무엇인가"
- 무엇인가 → 무엇을 하는가 → 특징 → 한계 순서
- 제목은 멋을 내도 되지만 정체나 역할을 말할 것
- 동사에는 대상을, 용어에는 처음 나오는 자리에서 풀이를
- 히어로·스크롤 연출 문구는 정의와 붙여 둘 것
- 사용자가 준 자료에 없는 사실은 만들지 않고, 비공개·스포일러 내용은 넣지 않을 것
- 다 쓴 뒤 각 섹션의 첫 문장만 이어 읽어 스스로 점검할 것

자세한 내용은 [SKILL.md](define-first-copy/SKILL.md)에 있습니다.

## 설치

**Claude Code**

`define-first-copy` 폴더를 아래 중 한 곳에 복사합니다.

- 모든 프로젝트에서 쓰기: `~/.claude/skills/define-first-copy/`
- 한 프로젝트에서만 쓰기: 프로젝트의 `.claude/skills/define-first-copy/`

**Claude 앱 (claude.ai)**

`define-first-copy` 폴더를 zip으로 묶어 설정의 스킬 메뉴에서 업로드합니다.

**그 밖의 AI**

스킬 기능이 없는 AI라면 `SKILL.md`의 본문을 프로젝트 지침이나 시스템 프롬프트에 붙여 넣어 씁니다.

## 사용

설치해 두면 AI가 웹사이트 문구를 쓸 때 알아서 불러옵니다. 직접 부르려면 Claude Code에서 `/define-first-copy`를 입력하거나, 요청에 "define-first-copy 스킬을 써서"라고 덧붙입니다.

설정 자료(문서, 캐릭터 시트, 붙여 넣은 글 등)를 함께 건네면 그 자료를 근거로 씁니다.
