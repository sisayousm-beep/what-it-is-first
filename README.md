# what it is first

AI로 웹사이트를 만들 때, 처음 보는 사람이 각 개념이 **무엇인지**부터 이해하도록 문구를 쓰게 하는 스킬입니다.

AI는 소개 문구에서 가장 인상적인 부분을 앞에 내세우기 쉽습니다. 특이한 성질, 큰 숫자, "~가 아니다" 같은 부정문이 정의보다 먼저 나오면, 처음 보는 사람은 무엇에 대한 이야기인지 모르는 채로 읽게 됩니다.

세계관 소개 사이트, 서비스·제품 소개, 단체나 포트폴리오 소개처럼 독자가 모르는 개념을 소개하는 페이지라면 어디에나 쓸 수 있습니다.

## 스킬이 지키게 하는 것

- 개념을 처음 꺼낼 때 첫 문장은 "그게 무엇인가"
- 무엇인가 → 무엇을 하는가 → 특징 → 한계 순서
- 제목은 멋을 내도 되지만 정체나 역할을 말할 것
- 동사에는 대상을, 용어에는 처음 나오는 자리에서 풀이를
- 히어로·스크롤 연출 문구는 정의와 붙여 둘 것
- 사용자가 준 자료에 없는 사실은 만들지 않고, 비공개·스포일러 내용은 넣지 않을 것
- 다 쓴 뒤 각 섹션의 첫 문장만 이어 읽어 스스로 점검할 것

자세한 내용은 [SKILL.md](what-it-is-first/SKILL.md)에 있습니다.
